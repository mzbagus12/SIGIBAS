# Ikon SI-GIBAS

Ikon launcher dibuat dengan bantuan ImageGen pada 30 Oktober 2026. Simbol anak, hati dan daun menggambarkan pendampingan serta pertumbuhan; warna hijau mengikuti aplikasi. Tidak ada teks kecil agar ikon tetap terbaca pada layar utama.

sigibas-icon-master.png adalah gambar utama. Resource Android dibuat pada ukuran 48, 72, 96, 144 dan 192 piksel melalui penskalaan teknis. Label launcher adalah SI-GIBAS. Perubahan hanya menyentuh aset dan nama tampilan, tanpa mengubah applicationId, logika, database atau backend.
